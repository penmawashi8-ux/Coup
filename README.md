# COUP - ブラフゲーム Web App

Coupボードゲームのオンライン実装。Next.js製、Vercelにそのままデプロイ可能。

## ゲームモード

- **CPU対戦**: 1〜5体のCPUと対戦（ブラウザ完結）
- **オンライン対戦**: ルームコードを共有してフレンドと対戦。人数が足りない場合はCPUが自動補充

## ルール概要

- 2〜6人のブラフ心理戦
- 各プレイヤーは2枚の非公開カードと2コインでスタート
- アクション → チャレンジ/ブロック → 解決 の順で進行
- 他プレイヤーの影響力（カード）を全て除去した最後の1人が勝利

### アクション
| アクション | 効果 | チャレンジ | ブロック |
|---|---|---|---|
| 収入 | +1コイン | 不可 | 不可 |
| 外国援助 | +2コイン | 不可 | Duke |
| クーデター | 7コイン支払い、対象が影響力喪失 | 不可 | 不可 |
| 徴税 (Duke) | +3コイン | 可 | — |
| 暗殺 (Assassin) | 3コイン支払い、対象が影響力喪失 | 可 | Contessa |
| 窃盗 (Captain) | 対象から2コイン盗む | 可 | Ambassador/Captain |
| 交換 (Ambassador) | Court山から2枚引いて交換 | 可 | — |

## セットアップ

```bash
npm install
npm run dev
```

## Vercelデプロイ

```bash
vercel deploy
```

> **注意**: ゲーム状態はサーバーのメモリに保存されます。Vercelのサーバーレス環境ではインスタンスをまたいだ状態共有ができないため、オンライン対戦は同一インスタンス内に限られます。永続化が必要な場合は `@vercel/kv` の追加を検討してください。
